# 🎥 MLCamera

**Умная камера для распознавания лиц и детекции машин**

## ✨ Что умеет

| Функция | Как работает |
|---------|-------------|
| 👤 **Кто пришёл** | Распознаёт членов семьи по лицу (InsightFace), отправляет уведомление + фото |
| 👾 **Незнакомец** | Отдельное уведомление, лицо сохраняется для автообучения |
| 🚗 **Машина проехала** | Детекция YOLO с OCR для чтения номеров |
| 📸 **Фото номера** | Вырезка + OCR → «А123ВС 777» |
| 🎨 **Цвет машины** | Гистограмма HSV → «белый, чёрный, серебристый...» |
| 🌙 **Ночное видение** | ИК-режим + усиление тёмных кадров для распознавания |
| ⏱️ **Трекинг (без спама)** | 2 минуты = 1 уведомление за проход |
| 🟢/🔴 **«Вошёл / вышел»** | Пересечение линии отслеживания в кадре |
| ⭐ **Свой номер vs чужой** | Белый список `car.known_plates` |
| 📊 **Голосование по номеру** | Голосование по нескольким кадрам OCR |
| 🌅 **Утренний дайджест** | Ежедневная сводка за 09:00: кто приходил, машины, незнакомцы |
| 🔧 **Мультиразрешение** | Маленький кадр для анализа при отсутствии движения |

## 🚀 Быстрый старт

### 1. Установка (Windows/Linux)
```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
# Linux: source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

### 2. Настройка
```bash
python scripts/make_dirs.py              # создать все папки
python scripts/add_person.py Аня         # добавить человека
```

### 3. Добавить фото
Положи 20-25 фото каждого в `data/datasets/raw/<имя>/`

### 4. Вырезать и запомнить
```bash
python scripts/collect_faces.py          # вырезать лица
python scripts/register_faces.py         # запомнить (эмбеддинги)
```

### 5. Настроить камеры
Открой `config/config.pc.yaml` → раздел `cameras:` → замени на `rtsp://ЛОГИН:ПАРОЛЬ@IP_КАМЕРЫ:554/stream1`

### 6. Уведомления (куда писать)
В том же `config/config.pc.yaml`, раздел `notify`:
```yaml
notify:
  telegram:
    bot_token: "123456789:AA...свой_токен"
    chat_ids:
      - "111111111"  # твой id
  push:
    topic: "мой_секретный_topic"
```

### 7. Запуск
```bash
python main.py                    # Запустить камеру с окном
python main.py --self-test         # Проверка уведомлений
```

## 📁 Структура проекта

```
data/
├── datasets/raw/<имя>/      ← фото членов семьи (класть сюда)
├── datasets/faces/<имя>/    ← вырезанные лица (collect_faces)
├── datasets/auto_unknown/   ← лица незнакомцев (авто-обучение)
├── models/                  ← веса YOLO/марки
├── videos/<камера>/         ← ВИДЕО с камер (ПК-версия)
├── events/<камера>/<дата>/  ← фото событий + вырезки номеров
├── db/ml_camera.db          ← база событий
└── logs/camera.log          ← логи
```

## 📋 Требования

| Компонент | Минимально / рекомендуемо |
|-----------|-------------|
| ОС | Windows 10/11, Linux |
| CPU | любой 4-ядерный; Ryzen 5 5600 — с запасом |
| RAM | от 8 ГБ |
| Видеокарта | не обязательна (всё на CPU). RX 5700 XT ускорит распознавание |
| Диск | 5 ГБ (модели + события + видео) |
| Камера | IP с RTSP и ИК-подсветкой (Xiaomi, Hikvision, Dahua, TP-Link...) |

## 🏠 Для запуска на компьютере (вариант «дома»)

Для запуска на сервере VPS (вариант «в облаке»):

| Параметр | Какой нужен |
|----------|-------------|
| **CPU** | 1-2 vCPU для 1-2 камер; 4 vCPU для 3+ камер |
| **RAM** | 1-2 ГБ (1-2 камеры); 4 ГБ (3+ камер) |
| **Диск** | от 10 ГБ SSD |
| **ОС** | Ubuntu 22.04 / 24.04 |
| **Сеть** | 1 Гбит; нужен доступ до камер |

## 🌙 Ночное видение

1. На камере включи **ИК-подсветку / режим «Авто»** (ночью картинка ч/б)
2. В конфиге стоит `camera.night_enabled: true` — тёмные кадры автоматически усиливаются
3. Порог, с которого кадр считается «ночным» — `camera.night_brightness_threshold: 60`
4. Добавь в датасет **2-5 ч/б фото** каждого члена семьи
