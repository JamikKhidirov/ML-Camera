# OBJECTS — животные и оставленные вещи

Две новые возможности на **тех же весах YOLO**, что уже используются для
людей и машин. Отдельная модель не скачивается и не обучается.

| Событие | Классы COCO | Уведомление |
|---|---|---|
| Животное в кадре | `dog`, `cat`, `bird` | «Собака в кадре» + фото |
| Оставленная вещь | `backpack`, `suitcase`, `handbag` | «Оставлен рюкзак» / «Оставлен чемодан» / «Оставлена сумка» |

> «Посылки» как отдельного класса в YOLO нет. Коробка/пакет рядом с домом
> обычно выглядит для модели как рюкзак, чемодан или сумка. Поэтому
> оставленная вещь определяется по **стационарности** трека.

---

## 1. Как это работает

1. YOLO за один прогон находит все объекты в кадре.
2. Из общего результата фильтруются машины, животные и вещи.
3. Для животных и вещей работает свой `CentroidTracker`.
4. **Животное**: после `min_frames` кадров уходит одно уведомление.
   Повтор — не раньше `cooldown_minutes`.
5. **Вещь**: трек запоминает центр. Если объект сместился сильнее порога —
   таймер неподвижности сбрасывается. Когда вещь стоит на месте
   `stationary_seconds`, уходит уведомление «Оставлена …».
6. Событие пишется в SQLite (`object_events`) и видно в веб-панели.

### Порог движения

```
порог = max(stationary_min_pixels, размер_вещи * stationary_move_ratio)
```

По умолчанию `max(8 px, 15% размера)`. Это компенсирует дрожание бокса
и разные разрешения камер.

### Почему это не срабатывает на человека с рюкзаком

Пока человек идёт, центр рюкзака смещается вместе с ним — таймер
неподвижности постоянно сбрасывается. Если человек снял рюкзак и ушёл,
рюкзак остаётся на месте и через `stationary_seconds` даёт событие.

## 2. Настройка

```yaml
objects:
  enabled: true
  max_disappeared: 20
  max_distance: 100

  animals:
    enabled: true
    classes: ["dog", "cat", "bird"]
    conf_threshold: 0.35
    min_frames: 2
    cooldown_minutes: 30

  packages:
    enabled: true
    classes: ["backpack", "suitcase", "handbag"]
    conf_threshold: 0.40
    min_frames: 3
    stationary_seconds: 45       # сколько секунд без движения = «оставлена»
    stationary_move_ratio: 0.15  # допустимое смещение относительно размера
    stationary_min_pixels: 8
    cooldown_minutes: 120
```

### Что подкрутить

| Ситуация | Что менять |
|---|---|
| Слишком много ложных «собак» | поднять `animals.conf_threshold` до `0.45–0.55` |
| Животное не замечается | снизить `conf_threshold` до `0.25–0.30` |
| Вещь «оставлена» слишком быстро | поднять `stationary_seconds` до `90–180` |
| Вещь не замечается | снизить `packages.conf_threshold` до `0.30` |
| Дрожание бокса сбрасывает таймер | поднять `stationary_move_ratio` до `0.25` |
| Слишком частые уведомления | поднять `cooldown_minutes` |
| Нужны другие животные | добавить COCO-класс в `animals.classes`, например `horse`, `cow`, `sheep` |

### Выключить отдельно

```yaml
objects:
  animals:
    enabled: false
  packages:
    enabled: false
```

Или полностью: `objects.enabled: false`.

## 3. Стоимость CPU

Детекция уже выполняется ради машин и людей. Животные и вещи — это только
фильтрация готового результата, поэтому **дополнительный прогон YOLO
не делается**. Расход добавляют лишь трекинг и редкие сохранения фото.

На слабом VPS можно оставить `objects.enabled: true`, но поднять
`analysis.detect_every_n_frames` и `stationary_seconds`.

## 5. Ограничения (честно)

- **Нет класса `package`.** Коробка может не детектироваться вообще, если
  YOLO не похож на неё ни на рюкзак, ни на чемодан, ни на сумку.
- **Маленькие объекты.** Вещь размером меньше ~30 px по высоте на кадре
  YOLO обычно не видит. Нужен нормальный зум/ракурс.
- **Ночь.** На ч/б ИК-кадре уверенность ниже. Проверьте
  `conf_threshold` и освещение.
- **Ложные срабатывания.** Собака на плакате, рюкзак в руках у неподвижно
  стоящего человека или сумка на стуле тоже могут дать событие.
- **Движение камеры.** Если камера поворачивается (PTZ), координаты плывут —
  стационарность определять нельзя, отключите `packages`.
- **Несколько одинаковых вещей.** Трекер связывает по центру; две сумки
  рядом могут «склеиться». Держите `max_distance` небольшим для вашего
  разрешения.

## 6. Диагностика

| Симптом | Причина / решение |
|---|---|
| нет событий о животных | проверь `objects.enabled`, `animals.enabled`, классы и `conf_threshold` |
| животное есть, уведомления нет | `min_frames` не набран или сработал `cooldown_minutes` |
| вещь не считается оставленной | она двигается/камера PTZ/мало `stationary_seconds` |
| события есть, фото нет | не хватает прав на запись в `data/events/` |
| в веб-панели нет вкладки | события пишутся в другую БД — проверь `database.path` |

Проверить детекцию на тестовом видео:

```bash
python main.py --config config/config.yaml --once --preview
```

В окне животные подсвечиваются жёлтым, вещи — синим.
