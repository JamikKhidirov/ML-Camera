# ЗАПУСК — подробно, шаг за шагом

Эта инструкция доводит проект от «скачал папку» до работающей камеры,
живого потока в браузере и настройки всех параметров.

> **Главное:** конфиг один — `config/config.yaml`. Его читают и камера,
> и веб-панель, и окно Tkinter. Других файлов настроек нет.

---

## 0. Что должно получиться

После запуска одной командой:

1. камера (по умолчанию — веб-камера ноутбука) начинает читать кадры;
2. в браузере открывается **http://127.0.0.1:8088**;
3. во вкладке **«Камеры»** идёт живой поток, поверх — рамки объектов
   и «чертёж лица» из 106 точек;
4. во вкладке **«🛠 Настройки»** можно менять FPS камеры, FPS потока,
   разрешение, модели, запись, уведомления — и сразу применять;
5. события (лица, машины, животные, вещи) складываются в историю.


## 2. Первый запуск на Windows (двойной клик)

### Шаг 1. Установка — `pc\setup.bat`

Дважды кликни **`pc\setup.bat`**. Он:

1. создаст `.venv` (виртуальное окружение);
2. поставит зависимости из `requirements.txt` и `requirements-pc.txt`;
3. скачает модели: YOLO, InsightFace, модель марки, ALPR;
4. предложит зарегистрировать лица из `data\datasets\raw\`
   (можно пропустить и сделать позже).

Первый запуск занимает **10–30 минут** — это нормально. Окно нельзя
закрывать до надписи «Готово».

Если PowerShell ругается на политику запуска, открой терминал в папке
проекта и выполни:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

### Шаг 2. Запуск — `pc\run_pc.bat` или `start_pc.bat`

Дважды кликни **`pc\run_pc.bat`** (либо `start_pc.bat` в корне).
Что произойдёт:

1. запустится `python main.py`;
2. откроется камера (первый кадр может занять **10–30 секунд**);
3. поднимется веб-панель на `127.0.0.1:8088`;
4. через ~2 секунды браузер откроется сам.

Если браузер не открылся — открой вручную:
**http://127.0.0.1:8088**

> Первые кадры могут быть тёмными, пока камера прогревается. Это не ошибка.

### Шаг 3. Проверка

Во вкладке **«Камеры»** должно быть:

- имя камеры и зелёный статус `работает`;
- живой поток (обновляется несколько раз в секунду);
- счётчик FPS и разрешение;
- рамки вокруг людей/машин и контур лица.

Если поток есть — всё запущено правильно.

| Способ | Что делать |
|---|---|
| Двойной клик | `start_pc.bat` или `pc\run_pc.bat` |

Остановить — закрыть окно консоли или `Ctrl+C`.

## 4. Настройка FPS и всех параметров

### Способ А — веб-панель (рекомендуется)

1. Открой **http://127.0.0.1:8088**.
2. Вкладка **«🛠 Настройки»**.
3. Меняй поля:

| Поле | Что делает | Обычные значения |
|---|---|---|
| `FPS камеры` (`camera.fps`) | сколько кадров в секунду читать | `30` плавно, `15` экономно, `0` — максимум камеры |
| `FPS live-потока` (`web.stream_fps`) | частота картинки в браузере | `10`, при хорошей сети `15` |
| `Качество JPEG` (`web.stream_quality`) | чёткость/трафик потока | `70`, для телефона `60` |
| `Ширина/высота` | разрешение кадра | `1280×720` |
| `Анализировать каждый N-й кадр` | нагрузка на ИИ | `4` на ноутбуке, `2` на ПК |
| `FPS записи` | частота видеофайлов | `12–15` |
| `Рамки объектов` / `«Чертёж лица»` | что рисовать на потоке | включено |
| `Запускать панель вместе с камерой` | автозапуск панели | включено |
| `Открывать панель в браузере` | автооткрытие вкладки | включено |

4. Нажми **«💾 Сохранить и применить»**.

Что произойдёт:

- значения проверятся (нельзя вписать FPS 999 или качество 5);
- файл `config/config.yaml` перезапишется, рядом появится
  `config.yaml.bak` — резервная копия;
- камеры перезапустятся в фоне и применят FPS/разрешение;
- рамки и «чертёж лица» обновятся сразу, без перезапуска.

> Смена `host`/`port`/`token` применяется только после перезапуска
> `main.py` — панель сама себя перезапустить не может.

### Способ Б — окно Tkinter

Дважды кликни **`settings.bat`** (или `python scripts/settings.py`).

Окно содержит те же вкладки, что и панель: Камеры, Камера и FPS, Анализ,
Движение, Лица, Машины, Животные и вещи, Запись, Веб-панель, Уведомления,
Дайджест, Логи.

- **💾 Сохранить** — записать в `config/config.yaml`;
- **🚀 Сохранить и применить** — записать и отправить работающей панели
  (камеры перезапустятся);
- **⟳ Перечитать** — вернуть значения из файла.

### Способ В — вручную

Открой `config/config.yaml` блокнотом. Ключевые строки:

```yaml
camera:
  width: 1280
  height: 720
  fps: 30            # FPS камеры

web:
  stream_fps: 10     # FPS live-потока
  stream_quality: 70 # качество JPEG
  overlay: true      # рамки
  face_mesh: true    # «чертёж лица»

recording:
  fps: 12            # FPS записи
```

## 5. Своя IP-камера

1. Узнай RTSP-адрес камеры (в приложении производителя).
   Обычно: `rtsp://логин:пароль@192.168.1.100:554/stream1`.
2. Открой **«🛠 Настройки» → Камеры** и добавь строку:

   | Имя | Источник | Включена |
   |---|---|---|
   | `Двор` | `rtsp://admin:pass@192.168.1.100:554/stream1` | ✅ |

3. Выключи веб-камеру (галочка «включена») или оставь обе.
4. **Сохранить и применить** — камеры перезапустятся.

В конфиге это выглядит так:

```yaml
cameras:
  - name: "Двор"
    source: "rtsp://admin:pass@192.168.1.100:554/stream1"
    enabled: true
```

Если IP-камера не открылась, сработает `camera.fallback_webcam: true`
и подключится веб-камера ноутбука — панель не останется пустой.

## 6. Linux / сервер

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/download_models.py
python scripts/install_alpr.py
python main.py
```

Без графики (сервер, нет браузера):

```bash
python main.py --no-web          # только камера
# или панель отдельно:
python scripts/web_panel.py --config config/config.yaml
```

Для доступа с другого компьютера:

```yaml
web:
  host: "0.0.0.0"
  token: "длинный-пароль"
```

и открывай `http://IP-СЕРВЕРА:8088/?token=длинный-пароль`.

## 8. Если что-то не работает

| Симптом | Что делать |
|---|---|
| `Порт 8088 занят` | закрой старый `python main.py` или смени `web.port` в настройках |
| Камера `error`, чёрный кадр | закрой Zoom/Teams/ Skype — они держат камеру; подожди 10–30 с |
| Браузер не открылся | открой http://127.0.0.1:8088 вручную |
| Панель просит токен | открой `http://127.0.0.1:8088/?token=ТВОЙ_ПАРОЛЬ` |
| Нет моделей | `python scripts/download_models.py` |
| Нет номеров | `python scripts/install_alpr.py`, затем `plate_engine` в настройках |
| «Настройки не сохранились» | панель запущена отдельным процессом — правь через `settings.bat` или перезапусти `main.py` |
| FPS не изменился | камера может игнорировать запрос; поставь `camera.fps: 15` и перезапусти камеру кнопкой «Стоп/Старт» |
| Telegram молчит | `python main.py --self-test`, проверь токен и `chat_ids` |

Логи: `data/logs/camera.log` и окно консоли.

```
data/events/           ← фото событий

data/db/               ← база событий и лица
data/datasets/raw/     ← фото людей (папка = имя)
```

Готово. Одна команда — `python main.py` — и всё работает.
