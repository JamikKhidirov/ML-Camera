# НАЧАЛО — пошагово для любого человека (даже если ты ни разу не программист)

Проект MLCamera делает из твоей камеры (например, видеокамеры на воротах)
умную: она узнаёт членов семьи по лицу, замечает машины, фотографирует
номера, и пишет тебе и родным в **Telegram** + **пуш на телефон**.

Эта инструкция — «для чайников». Иди по шагам, не пропускай.

## 1. Что вообще нужно

| Что | Зачем | Где взять |
|---|---|---|
| Python 3.10+ | запуск программ | https://python.org (галочка **Add to PATH** при установке!) |
| Видеокамера | чтобы она была «умной» | твоя IP-камера с RTSP или просто тестовое видео |
| Telegram-бот | чтобы слать уведомления | напиши **@BotFather** → `/newbot` → получи токен |
| Твой id в Telegram | чтобы бот писал тебе | напиши **@userinfobot** → узнай свой id |
| Приложение ntfy | пуш на телефон | поставь из Google Play / App Store |
| VPS-сервер (необязательно) | работать без твоего ПК, 24/7 | Timeweb/VDSina/Aeza, от ~300 ₽/мес |

## 2. Где лежат папки и что куда класть

Проект — это папка **MLCamera** (та, где ты сейчас читаешь этот файл).
Внутри:

```
MLCamera/
├── main.py                  ← запуск камеры (или MLCamera.exe)
├── config/
│   ├── config.pc.yaml       ← ★ НАСТРОЙКИ ПК-версии (ты правишь только его)
│   ├── config.vps.yaml      ← настройки серверной версии
│   └── config.yaml          ← общие настройки
├── data/                    ← ★ ВСЁ ЛИЧНОЕ живёт здесь
│   ├── datasets/
│   │   └── raw/ИМЯ/         ← ★ СЮДА КЛАДЁШЬ ФОТО ЛЮДЕЙ (папка = имя)
│   ├── events/              ← фото событий (что пришло в Telegram)
│   ├── videos/              ← видео с камер
│   └── db/                  ← база событий + запомненные лица
├── pc/
│   ├── build_exe.bat        ← собрать .exe с иконкой
│   ├── setup.bat            ← первый запуск (поставит всё нужное)
│   └── deploy_vps.py        ← авто-деплой на сервер
└── docs/                    ← вся документация
```

> В папке `data/` лежит файл `README.txt` — сверяйся с ним, если забыл,
> куда что класть.

## 3. Первый запуск на компьютере

**Способ А — самым простым двойным кликом (рекомендую):**

1. Дважды кликни **`pc\setup.bat`**.
   Он сам создаст окружение, поставит библиотеки (~10 минут) и скачает
   модели ИИ.
2. Дальше по инструкции ниже.

**Способ Б — вручную (для тех, кто знаком с консолью):**

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
pip install -r requirements-pc.txt
python scripts/download_models.py
```

## 4. Настройки: токен бота, кому писать, камеры

Открой файл **`config\config.pc.yaml`** обычным блокнотом
(правой кнопкой → «Открыть с помощью» → Блокнот).

Замени только то, что написано ниже — остальное не трогай:

### а) Telegram-бот

```yaml
notify:
  telegram:
    bot_token: "123456789:AA...токен"    # ← вставь токен от @BotFather
    chat_ids:
      - "111111111"                       # ← твой id (узнай у @userinfobot)
      - "222222222"                       # ← id мамы/папы/сестры — добавить строку
```

### б) Камеры

```yaml
cameras:
  - name: "Камера-1 (двор)"
    source: "rtsp://ЛОГИН:ПАРОЛЬ@IP_КАМЕРЫ:554/stream1"   # ← сюда свою
    enabled: true
```

- Логин/пароль камеры — из её приложения (Mi Home, Hik-Connect и т.п.);
- IP камеры — адрес в домашней сети;
- Проверить, что ссылка рабочая, можно в программе **VLC**:
  «Открыть сетевой поток» → вставить ссылку;
- Нет камеры? Сгенерируй тестовое видео:
  `python scripts/make_test_video.py` и укажи в `source` путь
  `data/test_video.mp4`.

### в) Пуши на телефон (необязательно, но удобно)

```yaml
  push:
    topic: "придумай_секретное_слово"     # ← своё слово
```
Поставь приложение **ntfy**, добавь свой topic — и пуши придут на телефон.

## 5. Фотографии людей — самое главное

Камера узнаёт людей по фотографиям, которые ТЫ ей дашь.

**Куда класть:** в папку `data\datasets\raw\ИМЯ\`, где ИМЯ — имя человека
**(только русскими буквами, как ты хочешь, чтобы камера его называла)**.

```
data\datasets\raw\Мама\        ← фото мамы
data\datasets\raw\Папа\        ← фото папы
data\datasets\raw\Я\           ← твои фото
data\datasets\raw\Бабушка\     ← фото бабушки
data\datasets\raw\Сестра\      ← фото сестры  (папку можно создать самому)
```

Папки уже созданы (Алексей, Ольга, Сергей, Аня, Катя) — открой и посмотри.

**Правила фото (10–25 штук на человека):**
- лицо крупно, одно лицо в кадре, без чужих людей рядом;
- разные ракурсы и освещение (анфас, чуть вбок);
- фото чёткое, лицо видно целиком;
- обычные фото с телефона подойдут. Ничего не обрезай и не называй.

**После того как кинул фото — запомни лица одной командой:**

```bash
python main.py --register
```

(Или дважды кликни `MLCamera.exe --register` — про exe см. раздел 7.)

Скрипт создаст недостающие папки, вырежет лица и запомнит их.
Увидишь сообщение «Зарегистрирован: Мама (фото=22)».

> Добавил нового человека? Создай `raw\НовоеИмя\`, кинь фото,
> запусти `--register`. Всё.

## 6. Запуск камеры

```bash
python main.py
```

- Откроется живое окно с видео и рамками вокруг людей/машин;
- видео пишется в `data\videos\<камера>\`;
- уведомления приходят в Telegram/ntfy.

Полезные команды:

| Команда | Что делает |
|---|---|
| `python main.py` | запуск (окно, запись, уведомления) |
| `python main.py --self-test` | проверить, что бот доносит уведомления |
| `python main.py --register` | запомнить лица из `raw\` |
| `python main.py --preview` | окно с рамками (если выключено в конфиге) |
| `python main.py --once` | проверить ~30 кадров и выйти |
| `python main.py --config config/config.vps.yaml` | серверная версия |

## 7. Сделать .exe с иконкой

Чтобы запускать камеру **двойным кликом** по красивой иконке (а не командой):

1. Сначала один раз пройди разделы 3–5 (чтобы были настройки и фото).
2. Дважды кликни **`pc\build_exe.bat`**.
   - Он поставит нужное и соберёт программу (~5–15 минут).
3. Результат: **`pc\dist\MLCamera\MLCamera.exe`** — создай себе ярлык
   на рабочий стол, двойной клик = камера работает.

> В папке с exe лежат `config\` и `data\`. Хочешь поменять настройки или
> добавить фото — меняешь там, без пересборки. Только `--register` для новых
> людей запусти через exe или вернись в исходную папку.

## 8. Автоматически хостить на сервере VPS

Хочешь, чтобы камера работала **круглосуточно без твоего ПК** — арендуй
сервер (VPS, ~300 ₽/мес) и разверни проект **одной командой**.

1. Купи VPS: **Ubuntu 22.04, 1 vCPU, 1 ГБ RAM, 10 ГБ SSD**.
2. Укажи настройки сервера в файле **`pc\deploy.yaml`**
   (создаётся сам при первом запуске; пароль в git не попадёт):

   ```yaml
   host: "185.23.45.67"     # IP сервера
   user: "root"
   password: "твой_пароль"
   ```

3. Запусти:

   ```bash
   python pc\deploy_vps.py
   ```

4. Всё. Скрипт упакует проект (вместе с твоим конфигом и базой лиц),
   зальёт на сервер, поставит Docker и запустит камеру.

Проверка на сервере:
```bash
docker ps
docker logs -f ml_camera
```

> Камера должна быть доступна серверу: либо WireGuard между домом и VPS,
> либо проброс порта на роутере. Подробно: `docs/VPS_CAMERAS.md`.

## 9. Частые вопросы и что делать

| Проблема | Что сделать |
|---|---|
| «Не открывается источник» | проверь RTSP в VLC; включи RTSP в приложении камеры; проверь логин/пароль/IP |
| Ночью тёмные снимки | включи ИК-подсветку на камере; добавь 2–5 ч/б фото в датасет |
| Не узнаёт человека | больше фото; снизь `face.similarity_threshold` до 0.40 |
| Номер машины не читается | поставь камеру ниже/под углом; в ПК-версии уже стоит `easyocr` |
| Как добавить человека | создай `raw\Имя\`, кинь фото, запусти `--register` |
| Спам-уведомления | подними `car.cooldown_minutes` и `face.cooldown_minutes` |
| «Куда делись фото?» | на VPS они удаляются (`delete_images_after_send: true`) |
