# DATASET — куда кидать фото и сколько их нужно

## Куда именно кидать фотки?

Папки уже созданы **по настоящим именам** (можно переименовать под себя):

```
data/datasets/raw/
├── Алексей/   ← сюда 25 твоих фото (в папке README.txt с подсказкой)
├── Ольга/     ← сюда 25 фото мамы
├── Сергей/    ← сюда 25 фото папы
├── Аня/       ← сюда 25 фото старшей сестры
└── Катя/      ← сюда 25 фото младшей сестры
```

Имя папки = имя в уведомлениях («**Аня у камеры**»). Подпись «кто есть кто»
лежит прямо в каждой папке — файл `README.txt`.

Переименовать папки под свою семью — `python scripts/organize_folders.py`
(в нём таблица старых имён → новых). Добавить ещё человека:

```bash
python scripts/add_person.py Бабушка
```

Затем выполни:

```bash
python scripts/collect_faces.py          # вырезать лица -> data/datasets/faces/<имя>/
python scripts/register_faces.py         # запомнить -> data/db/embeddings.json
```

Готово — камера начнёт присылать «**кто пришёл**» по имени.

## Сколько фото каждому

| Человек | Папка | Рекомендую | Минимум |
|---|---|---|---|
| Ты | `Алексей` | 25 | 10 |
| Мама | `Ольга` | 25 | 10 |
| Папа | `Сергей` | 25 | 10 |
| Старшая сестра | `Аня` | 25 | 10 |
| Младшая сестра | `Катя` | 25 | 10 |

## Как зовут — где задать?

Имена в уведомлениях = **имена папок** (`data/datasets/raw/<имя>/`). Они же
прописаны в `config/config.yaml` → `people.names`:

```yaml
people:
  names:
    Алексей: "Алексей"      # папка -> как пишем в уведомлении
    Ольга: "Ольга"
    Сергей: "Сергей"
    Аня: "Аня"
    Катя: "Катя"
```

В уведомлении будет «**Аня у камеры**». Добавил человека — добавь строку сюда.

## Раскладка 25 фото (для каждого человека)

| Вид | Кол-во | Зачем |
|---|---|---|
| Анфас (прямо в камеру) | 5 | база |
| Поворот влево/вправо | 6 | камера видит сбоку/снизу |
| Наклон головы вверх/вниз | 4 | разная высота установки |
| Разное освещение (день/лампа/сумерки) | 6 | смена света |
| Эмоции (улыбка, серьёзно) | 4 | живое лицо |

## Требования к фото

- Лицо занимает минимум 1/3 кадра, чёткое, без смаза.
- Размер от 800×600, лучше больше.
- Не снимай двух человек в одном кадре — оба попадут в датасет того, чья папка.
- Форматы: `.jpg`, `.jpeg`, `.png`.
- Добавь 3-5 **чёрно-белых фото с ИК-подсветкой** (ночная камера) — модель
  выучит ночной вид лица, распознавание ночью станет надёжнее.

## Авто-обучение: камера сама копит фото незнакомцев

Когда к камере подходит человек, которого нет в базе, его лицо автоматически
сохраняется в `data/datasets/auto_unknown/` (если `face.auto_capture_unknown: true`).

Чтобы «научить» камеру узнавать нового человека:

1. Открой `data/datasets/auto_unknown/` и просмотри фото.
2. Отбери 15-25 удачных и переложи в `data/datasets/raw/<имя>/`.
3. Добавь в `people.names` строку: `<имя>: "Настоящее имя"`.
4. Выполни:
   ```bash
   python scripts/collect_faces.py
   python scripts/register_faces.py
   ```
5. Всё — камера теперь знает этого человека по имени.

## Данные для машин

Для **номеров** и **цвета** датасет не нужен (OCR + гистограмма).
Для **марки** — опциональное обучение классификатора (см.
`scripts/train_brand_classifier.py`). Пока не обучено — марка `unknown`,
на номера и цвет это не влияет.
