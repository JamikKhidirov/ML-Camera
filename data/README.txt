=========================================================
 MLCamera — СЮДА КУДА ЧТО КЛАСТЬ (самое важное!)
=========================================================

Папка data/ — это "хранилище" камеры. Сюда складываются
фотографии людей, события, видео, база данных. Всё, что
тут появится, НЕ попадает в GitHub (в интернет) — это
твои личные данные, они остаются только на компьютере.

---------------------------------------------------------
 ФОТОГРАФИИ ЛЮДЕЙ (самое главное!)
---------------------------------------------------------

Чтобы камера узнавала людей, положи фотографии в папки:

    data/datasets/raw/ИМЯ/     <-- СЮДА, где ИМЯ = имя человека

Например:

    data/datasets/raw/Мама/        <- фото мамы
    data/datasets/raw/Папа/        <- фото папы
    data/datasets/raw/Я/           <- твои фото
    data/datasets/raw/Бабушка/     <- фото бабушки

Папки с именами уже созданы. ОТКРОЙ любую папку — внутри
лежит файл README.txt с подсказкой.

Правила для фото (10-25 штук на человека):
  - одно лицо крупно, без других людей рядом;
  - разные ракурсы (анфас, чуть вбок), разный свет;
  - на фото должно быть ВИДНО лицо целиком;
  - можно телефоном, главное — чётко.
  - НЕ нужно обрезать или переименовывать — сам разберётся.

После того как кинул фото:
  1) дважды кликни MLCamera.exe --register
     (или выполни:  python main.py --register)
  2) всё, камера запомнила людей.

Добавил нового человека? Просто создай папку
data/datasets/raw/НовоеИмя/, кинь фото и запусти --register.

---------------------------------------------------------
 ОСТАЛЬНЫЕ ПАПКИ (создаются сами, руками НЕ трогай)
---------------------------------------------------------

    data/datasets/faces/<Имя>/   вырезанные лица (делает --register)
    data/datasets/auto_unknown/  фото незнакомцев (для обучения)
    data/datasets/cars/          фото машин (для обучения маркам)
    data/models/                 модели ИИ (yolov8, марки) — качаются сами
    data/db/                     база событий и лица (embeddings.json)
    data/events/<камера>/<дата>/ фото событий (что прислано в Telegram)
    data/videos/<камера>/        ВИДЕО с камер (только на ПК)
    data/logs/                   логи камеры (для разбора ошибок)
    data/snapshots/              запасные снимки

---------------------------------------------------------
 ГДЕ НАСТРОЙКИ (токен бота, id, камеры)?
---------------------------------------------------------

Всё настройки в файле:  config/config.pc.yaml
Открой его блокнотом и замени:
  - notify.telegram.bot_token  -> токен твоего бота (у @BotFather)
  - notify.telegram.chat_ids   -> id аккаунтов, кому писать (у @userinfobot)
  - cameras[].source           -> ссылки на твои камеры rtsp://логин:пароль@IP
  - notify.push.topic          -> секретное слово для пушей ntfy
Подробно — в docs/НАЧАЛО.md
